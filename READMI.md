## Descripción del proyecto
Plantix es un proyecto que busca ayudar a las personas a cuidar sus plantas. Utiliza un sensor de humedad que detecta cuándo la tierra necesita agua y avisa al usuario mediante un sistema de alerta. Su objetivo es facilitar el cuidado de las plantas y evitar que se sequen por falta de riego.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Arduino
- Sensor de humedad del suelo
- GitHub
- Netlify

## Objetivo
Crear una herramienta sencilla que permita reconocer cuándo una planta necesita agua y ayude a las personas a mantenerla en buen estado.
